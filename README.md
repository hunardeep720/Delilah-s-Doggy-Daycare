# 🐶 Delilah's Doggy Daycare

**Delilah's Doggy Daycare** is a web-based pricing tool that allows users to view and calculate dog daycare costs based on selected days and time preferences (full day or half day). Built using **HTML**, **CSS**, and **JavaScript**, the project provides an interactive and user-friendly experience for pet owners.

---

## 🧑‍💻 My Role – Front-End Developer

I was responsible for designing the interface and implementing the pricing logic for the daycare service.

### ✅ Key Responsibilities:
- Built a clean and responsive UI using **HTML** and **CSS** for easy navigation and interaction.
- Developed dynamic pricing functionality with **JavaScript** to calculate total costs based on user-selected days and time durations (full day or half day).
- Focused on creating a user-friendly experience with real-time updates as users adjust options.

---

## 🚀 Technologies Used
- **HTML**
- **CSS**
- **JavaScript**

---

## 📦 Features
- Day selection for dog daycare
- Options for **Full Day** or **Half Day** pricing
- Real-time cost calculation
- Responsive layout for mobile and desktop
